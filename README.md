# 早知道可视化编辑器

由桌面文件“早知道.html”原样发布，在线入口为 `index.html`。字体、图片与表格导入库包含在页面中。

在线访问：https://baiyangsake.github.io/zaozhidao/

## 使用说明

打开页面后可编辑内容、添加活动组并导出图片或 HTML。当前上传文件为活动组为空的模板。编辑器没有云端保存服务；修改后请使用页面的保存 HTML 或导出功能保留结果。刷新或关闭网页可能丢失未导出的修改。

## 更新网站

用新版本替换仓库 main 分支根目录中的 index.html；GitHub Pages 会重新发布。
